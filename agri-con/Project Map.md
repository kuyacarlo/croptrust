# 🗺️ Project Map: CropTrust

CropTrust is a decentralized forward-contract marketplace for agricultural commodities.

## 🏗️ Current Architecture
- **Blockchain**: [[Stellar Soroban]] (Smart Contracts)
- **Satellite Data**: [[openEO]] (Sentinel-2 NDVI)
- **AI Analysis**: [[NVIDIA Llama 3.3]] (Crop Health Summaries)
- **Frontend**: [[Next.js Frontend]]

## 🚀 Core Features
- [[Crop NFTs]] - Verifiable assets representing harvests.
- [[USDC Escrow]] - 70/20/10 split for payment security.
- [[Satellite Verification]] - NDVI-gated listing process.
- [[Farmer ID Verification]] - On-chain identity.
- [[Review System]] - Buyer ratings & feedback after settlement.
